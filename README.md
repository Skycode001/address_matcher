# Общее описание

**Address Matcher** — высокопроизводительная система для поиска и нормализации адресов, разработанная для работы с базой данных из **523 316 адресов**.

Система использует комбинацию методов:

- Нормализация адресов с помощью регулярных выражений
- ML-модель (логистическая регрессия) для ранжирования кандидатов
- Гибридный скоринг с весовыми коэффициентами
- Кэширование для ускорения повторных запусков

## Ключевые характеристики

| Характеристика | Значение |
|---------------|----------|
| Размер базы | 523 316 адресов |
| Точность поиска | 87–100% |
| Скорость поиска | 50–100 мс |
| Время загрузки (с кэшем) | 2–3 секунды |
| Время загрузки (без кэша) | ~3 минуты |

# Нормализация адресов

## Общая схема

```text
Вход:
"Таллинская ул. д. 19 к. 1"

1. Нижний регистр
2. Замена ё → е
3. Реверс слов (при необходимости)
4. Обработка сокращений
5. Обработка размеров улиц (М./Б.)
6. Перестановка номерных улиц
7. Явная обработка д13 → дом 13
8. Разбор слитных форм 17к2с2
9. Замена сокращений через словарь
10. Финальная очистка

Выход:
"таллинская улица дом 19 корпус 1"
```

# ML модель и расчет скоринга

## Модель

```python
from sklearn.linear_model import LogisticRegression

model = LogisticRegression(
    random_state=42,
    max_iter=1000,
    class_weight='balanced',
    C=1.0
)
```

---

## Признаки модели

| № | Признак | Вес | Описание |
|----|---------|-----|----------|
| 1 | ratio_norm | 0.20 | Схожесть нормализованных адресов |
| 2 | ratio_street | 0.15 | Схожесть названий улиц |
| 3 | token_sort_ratio | 0.10 | Сортировка слов |
| 4 | partial_ratio | 0.05 | Частичное совпадение |
| 5 | phonetic_ratio | 0.05 | Фонетика |
| 6 | prefix_match | 0.05 | Первые 5 букв |
| 7 | house_match | 0.20 | Совпадение дома |
| 8 | corpus_match | 0.05 | Совпадение корпуса |
| 9 | length_ratio | 0.05 | Соотношение длины |
| 10 | type_match | 0.10 | Тип улицы |

---

## Формула итогового скора

```text
FINAL_SCORE =
    0.25 * (FUZZY_SCORE / 100)
  + 0.35 * ML_SCORE
  + 0.40 * HYBRID_SCORE
```

Где:

- `FUZZY_SCORE` — результат нечеткого поиска
- `ML_SCORE` — вероятность модели
- `HYBRID_SCORE` — взвешенная сумма признаков

---

## Бонусы и штрафы

| Условие | Действие |
|----------|-----------|
| Полное совпадение | final_score = 1.0 |
| Совпал номер дома | +0.4 |
| Совпала улица | +0.3 |
| Лишняя буква в номере | кандидат отклоняется |
| Разные номера домов | score = 0 |

# Устранение неполадок

## Долгая загрузка при первом запуске

**Причина:** создается кэш.

**Норма:**

- первый запуск: ~3 минуты
- последующие: 2–3 секунды

---

## ImportError: openpyxl

```bash
pip install openpyxl
```

---

## DtypeWarning при загрузке CSV

Добавить в `main.py`:

```python
warnings.filterwarnings(
    'ignore',
    category=pd.errors.DtypeWarning
)
```

---

## Адрес не найден

Возможные причины:

- отсутствует номер дома;
- опечатка в названии улицы;
- адрес отсутствует в базе;
- для ТиНАО/ЗелАО не добавлено ключевое слово.
